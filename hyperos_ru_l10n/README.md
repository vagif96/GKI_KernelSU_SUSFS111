# Русский язык для HyperOS 4.0 CN (POCO F5 / marble)

Модуль KernelSU / APatch / Magisk, который переводит на русский китайскую прошивку
`marble-full-OS4.0.0.26.XPKCNXM-17.0.zip` (порт HyperOS 4.0 с Redmi K90, Android 17).

В этой прошивке русский язык вырезан полностью — даже из `framework-res` и «Настроек».
Модуль возвращает его через **статические RRO-оверлеи**: системные APK не меняются и
не переподписываются, поэтому риск бутлупа минимален, а удаление модуля полностью
возвращает прошивку в исходное состояние.

* 52 оверлея, ≈ 53 000 строк перевода;
* перевод — сообщество xiaomi.eu (`ingbrzy/hyperos-xml-1.0-russian`, коммит `024e348`, CC BY-NC-SA 3.0);
* при установке язык системы переключается на `ru-RU`, при удалении — возвращается прежний.

## Установка

1. Установите `HyperOS4_CN_RU_l10n_v1.0.zip` через KernelSU / APatch / Magisk.
2. Перезагрузитесь — система загрузится на русском.
3. Если язык сбросился, нажмите кнопку «Действие» (Action) у модуля в KernelSU и перезагрузитесь.

приложение: с лишними/несовместимыми `%`-спецификаторами, ссылками на ресурсы, другим
числом элементов массива (всего 67 строк).

## Известные ограничения

* **Рабочий стол (MiuiHome)** в HyperOS 4 написан на Flutter — его тексты лежат внутри
  `libapp.so`, оверлеями их не перевести. Пока они будут на английском.
* **Камера, установщик пакетов, ContentCatcher** используют обфусцированные имена
  ресурсов; камера и установщик и так содержат русский язык в прошивке.
* Приложения, для которых нет перевода в xiaomi.eu (HyperPhone, Toolbox, Accessibility,
  MediaViewer, MiMediaEditor, Screenshot, AOSP-утилиты и т. п.), отображаются на
  английском (запасной язык по умолчанию), а не на китайском.
* Новые строки HyperOS 4.0, которых ещё нет в репозитории xiaomi.eu, тоже будут на английском.
* Сервисы Google (GMS, Play, Gboard, WebView) содержат русский язык сами по себе.

## Пересборка (новая версия прошивки или обновлённый перевод)

```sh
apt install zstd e2fsprogs aapt zipalign apksigner default-jre-headless android-sdk-platform-23 zip
pip install androguard loguru
hyperos_ru_l10n/tools/build.sh marble-full-OS4.0.0.xx.XPKCNXM-17.0.zip /tmp/hyperos-work
```

`tools/`:
* `lpparse.py` — разбор таблицы разделов `super.img`;
* `arsc.py` — парсер `resources.arsc` (поддерживает sparse/offset16/compact-записи Android 15+);
* `build_overlays.py` — фильтрация перевода и сборка подписанных оверлеев;
* `map.txt` — соответствие папок перевода xiaomi.eu и пакетов прошивки;
* `coverage.py` — отчёт о покрытии перевода по приложениям.
